## Non-blocking observations (future sweep, not this cycle)

1. **`advisor.py` `limit=1000` is a magic number in a router** — CLAUDE.md says one number lives
   in `docs/thresholds.md`. Worse, membership is still LIMIT-based: a crawl with >1000
   issue-bearing pages would still false-reject (now loudly, via the truncation warning). The
   P9-class-correct fix is membership without a limit (`SELECT url … WHERE job_id` or an
   EXISTS/IN check per submitted URL), which makes the limit knob disappear entirely.
2. **Disclosure phrasing is now triplicated** — `_total_issues_figure` (report_generator.py),
   the PDF category row f-strings, and the Excel disclosure column all render the same
   "N scored / N not scored" idea. Drift risk (the P16/P24 shape that produced P5.2). A shared
   phrasing helper would make the three agree the way the two SQL/Python predicates now do.
3. **Pre-existing lint warning** — `SummaryPanel.jsx:1` imports `React` unused (new JSX
   transform). Not introduced by this cycle; harmless until `--quiet` semantics change.
